\#Comprehensive Energy Analysis Toolchain (综合能源全链路数据分析工具集)



本项目是一个服务于新型电力系统与综合能源项目（如虚拟电厂 VPP、零碳园区）的全链路模块化工具集。利用大模型长链推理与代码生成能力，实现了从前期空间规划、中期高频交易数据清洗到后期实时监测大屏的分布式数智化工作流。



\## 模块说明



\### 1. 空间地理标记模块 (Geo-Mapper)

\- \*\*功能描述\*\*：辅助前期项目选址与勘探，通过 AI 协同编写地理编码脚本，自动将多源零散站点与物理网格数据转化为高精度空间地图标记图层。



\### 2. 高频数据解析与 HTML 动态渲染模块 (Data-Cleaner \& Chart-Renderer)

\- \*\*功能描述\*\*：针对省侧电力市场高频时序数据（电价、负荷流），利用 AI 驱动的数据清洗逻辑（Python/VBA）进行多源对齐与异常值过滤，并自动生成无错位的 HTML/Chart.js 动态图表响应式报表，有效解决短周期数据堆叠图错位问题。



\### 3. Vue 3 能源监测大屏模块 (Vue 3 Energy Dashboard) `\[Developing]`

\- \*\*功能描述\*\*：面向后期站点实时动态监测，采用 Vue 3 架构深度协同开发。该模块旨在无缝对接工商业站点 BMS 实时功率状态，提供毫秒级能源流向的闭环可视化大屏底座。
